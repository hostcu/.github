# Katkıda Bulunma Rehberi

Hostcu projelerine katkıda bulunduğunuz için teşekkür ederiz.

## Başlamadan önce

1. İlgili depodaki README ve varsa proje özelindeki katkı kurallarını okuyun.
2. Mevcut issue ve pull request'leri kontrol ederek aynı konunun daha önce açılmadığından emin olun.
3. Büyük değişikliklere başlamadan önce bir issue açarak yaklaşımı tartışın.
4. Güvenlik açıklarını herkese açık issue olarak bildirmeyin. Bunun için `SECURITY.md` dosyasını kullanın.

## Pull request kuralları

- Değişikliği mümkün olduğunca küçük ve tek amaca odaklı tutun.
- Açıklayıcı commit mesajları kullanın.
- Mevcut kod stiline uyun.
- Davranış değişikliği varsa README veya ilgili dokümantasyonu güncelleyin.
- Mümkünse test ekleyin veya değişikliğin nasıl test edildiğini PR açıklamasında belirtin.
- Gereksiz bağımlılık eklemeyin.
- Gizli anahtar, parola, token, kişisel veri veya üretim ortamına ait yapılandırma göndermeyin.

## Commit mesajı önerisi

Kısa ve anlaşılır bir format tercih edin:

```text
fix: yanlış disk kullanım hesabını düzelt
feat: DirectAdmin desteği ekle
docs: kurulum adımlarını güncelle
refactor: servis kontrolünü sadeleştir
```

## Lisans

Bir katkı göndererek katkınızın ilgili deponun lisansı altında yayımlanmasını kabul etmiş olursunuz.
