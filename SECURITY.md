# Güvenlik Politikası

Hostcu projelerinde güvenlik bildirimlerini ciddiye alıyoruz.

## Güvenlik açığı bildirimi

Bir güvenlik açığı tespit ettiyseniz **herkese açık issue açmayın** ve açığın ayrıntılarını herkese açık kanallarda paylaşmayın.

Bildirim için:

- E-posta: [info@hostcu.net](mailto:info@hostcu.net)
- Konu: `[SECURITY] GitHub - depo adı`

Mümkünse aşağıdaki bilgileri ekleyin:

- Etkilenen depo ve sürüm/commit
- Açığın teknik açıklaması
- Yeniden üretme adımları
- Olası etki
- Varsa örnek kod veya ekran görüntüsü
- Önerdiğiniz çözüm

## Kapsam

Her deponun desteklenen sürümleri farklı olabilir. Projeye özel bir `SECURITY.md` bulunuyorsa öncelikle o politika geçerlidir.

Bildirim incelenmeden önce açığı kamuya açıklamamanızı rica ederiz.
