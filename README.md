# Hostcu GitHub Yapılandırması

Bu depo, [Hostcu](https://www.hostcu.net/) GitHub organizasyonunun profil ve topluluk standartlarını içerir.

- Organizasyon profili: `profile/README.md`
- Katkı rehberi: `CONTRIBUTING.md`
- Güvenlik politikası: `SECURITY.md`
- Destek politikası: `SUPPORT.md`
- Davranış kuralları: `CODE_OF_CONDUCT.md`
- Issue şablonları: `ISSUE_TEMPLATE/`
- Pull request şablonu: `PULL_REQUEST_TEMPLATE.md`

> Bu depo ürün kodu içermez. Hostcu tarafından yayımlanan projeler organizasyon altındaki ayrı depolarda yer alır.
