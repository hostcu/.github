# Destek

Bu GitHub organizasyonu ağırlıklı olarak açık kaynak projeler, geliştirici araçları ve teknik kaynaklar içindir.

## Projeyle ilgili sorunlar

Bir Hostcu GitHub projesinde hata veya özellik talebi varsa ilgili deponun **Issues** bölümünü kullanın.

Issue açarken:

- Kullandığınız sürümü belirtin.
- İşletim sistemi ve çalışma ortamını yazın.
- Hata mesajlarını mümkünse eksiksiz paylaşın.
- Sorunu yeniden üretme adımlarını ekleyin.
- Parola, API anahtarı, token veya müşteri verisi paylaşmayın.

## Hostcu hizmetleriyle ilgili destek

Hosting, sunucu, alan adı, lisans veya müşteri hesabınızla ilgili konular GitHub üzerinden yürütülmez.

Resmî destek ve iletişim için [hostcu.net](https://www.hostcu.net/) kanallarını kullanın.

## Güvenlik açıkları

Güvenlik açıklarını issue olarak açmayın. `SECURITY.md` dosyasındaki bildirim yöntemini kullanın.
